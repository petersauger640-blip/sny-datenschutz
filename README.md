Datenschutzerklärung für den Browser SNY von „Stepz Studios“, veröffentlicht über GitHub Pages unter https://stepzstudios.github.io/sny-datenschutz/. Die Seite `index.html` ist statisches HTML, erzeugt aus `DATENSCHUTZ.md` im Repository von SNY (Stand 07.10.2026); sie setzt keine Cookies, lädt keine Inhalte anderer Anbieter und enthält keine Skripte, Analyse- oder Trackingwerkzeuge.
